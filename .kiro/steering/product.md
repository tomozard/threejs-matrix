# Product Overview

Matrix Effect is a Next.js web application that creates an interactive Matrix-style digital rain effect using Three.js. The application features multi-language character support including Thai, Japanese, Korean, Arabic, Russian, French, and English characters.

## Key Features
- Real-time animated character rain effect with WebGL rendering
- Multi-language character sets (8 languages + symbols)
- Interactive controls (mouse, keyboard shortcuts)
- Real-time performance statistics display
- Responsive design that adapts to screen size
- Variable character sizes and fade effects

## User Interactions
- Mouse click: Toggle between normal (1x) and fast (3x) speed
- Space: Pause/Resume animation
- Arrow keys: Increase/decrease speed incrementally
- Automatic column generation based on screen width

## Technical Focus
This is a visual effects demonstration project showcasing Three.js integration with React/Next.js for creating smooth, performant animations with complex character rendering and real-time user interaction.
